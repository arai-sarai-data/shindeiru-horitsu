# 死んでいる法律発見器

何十年も、誰も手を入れていない法律がある。e-Govの全法律から、最後に改正されてから長くたった法律を探します。

**サイト：** https://arai-sarai-data.github.io/shindeiru-horitsu/

- データは公式の公開データを `fetch.py` が取得・検証して作ります（毎月自動更新）。
- 元データの形式が想定と違うときは公開を止め、前回の正しいデータを残します。
- 誤りの訂正・削除のご連絡：arai-sarai-data@proton.me
